# ONYX-Pro Releases

Official software and firmware releases for the ONYX-Pro robotic chess system.

ONYX-Pro is an integrated robotic chess platform combining custom mechanical design, dedicated electronics, embedded firmware and Raspberry Pi software.

This repository provides the official binary releases required to operate the ONYX-Pro system.

## Downloads

Official releases are published through [GitHub Releases](../../releases).

Each release may include:

- **Raspberry Pi System Image (`.img`)**: Complete software environment for ONYX-Pro.
- **RP2040 Firmware (`.uf2`)**: Compiled firmware for the motion-control system.
- **Release Documentation**: Installation instructions, version information and SHA-256 checksums.

## Hardware Compatibility

ONYX-Pro software and firmware are developed specifically for the ONYX-Pro mechanical and electronic architecture.

The software, firmware and hardware are designed to work together as one integrated system. Compatibility with other mechanical or electronic configurations is not guaranteed.

## Versioning

Official releases use semantic versioning:

`vMAJOR.MINOR.PATCH`

Each release identifies a compatible combination of ONYX-Pro software and firmware.

## Installation

Please follow the installation instructions and documentation included with each release.

Always use the software image and firmware provided for the same release version.

## Project

ONYX-Pro is a custom robotic chess system featuring a SCARA robotic arm, magnetic piece detection, RP2040 motion control and Raspberry Pi software integrated with the Stockfish chess engine.
