# ONYX-Pro Firmware Releases

Official firmware releases for the ONYX-Pro robotic chess system.

ONYX-Pro is an integrated robotic chess platform combining custom mechanical design, dedicated electronics, embedded firmware and Raspberry Pi software.

This repository provides the official compiled firmware binaries specifically developed for the ONYX-Pro motion-control hardware.

## Downloads

Official firmware releases are published through [GitHub Releases](../../releases).

Each release may include:

- **RP2040 Firmware Package (`.zip`)**: Complete firmware distribution package.
- **Compiled Firmware (`.uf2`)**: Binary firmware for the RP2040-Zero motion-control board.
- **Release Documentation**: Installation instructions, version information and SHA-256 checksums.

## Hardware Compatibility

The firmware is developed specifically for the ONYX-Pro electronic and mechanical architecture.

It is designed to operate with the dedicated ONYX-Pro motion-control electronics, motor drivers, sensors and mechanical system.

Compatibility with other hardware configurations is not guaranteed.

## Versioning

Official firmware releases use semantic versioning:

`vMAJOR.MINOR.PATCH`

Each release represents a specific version of the ONYX-Pro RP2040 firmware.

Previous releases remain available through the GitHub Releases archive.

## Installation

Please follow the installation instructions included with each firmware package.

Always verify the downloaded ZIP file using its corresponding SHA-256 checksum before installation.

Make sure you use the firmware version intended for your ONYX-Pro hardware configuration.

## Project

ONYX-Pro is a custom robotic chess system featuring a SCARA robotic arm, magnetic piece detection, RP2040 closed-loop motion control and Raspberry Pi software integrated with the Stockfish chess engine.
